# 『스타트 위드 와이』 책 추천 영상 — 제작 패키지

스텔라가 **녹음·촬영만 하면** 바로 편집에 들어갈 수 있도록 만든 자료 모음입니다.
영상 길이 약 5분 05초 (가로 16:9) + 60초 쇼츠 컷 (세로 9:16).

## 작업 순서

1. **`02-teleprompter.md`** 를 폰에 띄우고 대본대로 촬영·녹음
2. 편집 툴에 영상 올린 뒤 **`cards/`** 의 PNG를 해당 타임코드에 배치
3. **`03-subtitles.srt`** 임포트 → 녹음 실제 길이에 맞춰 싱크 조정
4. **`01-production-script.md`** 의 편집 가이드대로 컷·BGM·무음 구간 정리
5. **`06-publish-kit.md`** 의 제목·설명란·고정댓글로 업로드
6. 같은 소스로 **`05-shorts-cut.md`** 의 60초 버전 재편집

## 카드 수정하고 다시 뽑기

색·문구를 바꾸려면 `04-title-cards.html` 상단 `:root`의 `--gold`, `--ink`, `--paper` 값과
카드 텍스트만 고치면 됩니다. 그 뒤 브라우저에서 파일을 열고 하단 **1:1 (캡처용)** 버튼을 눌러
카드 영역을 캡처하면 끝입니다.

`#one=T3` 처럼 해시를 붙이면 해당 카드 하나만 실제 크기로 표시됩니다 (`&step=2`로 단계 지정 가능).
헤드리스 크롬이 있다면 자동 렌더링도 됩니다:

```bash
chrome --headless=new --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1920,1080 --screenshot=cards/T1.png \
  "file://$PWD/04-title-cards.html#one=T1"
```

## 폰트

카드는 **Noto Sans KR**(본문·제목)과 **Manrope**(영문 레이블)로 만들었습니다.
스텔라 브랜드 폰트가 따로 있으면 `04-title-cards.html`의 `--kr` 변수만 바꾸면 전체에 적용됩니다.
