# 낭독 대본 (텔레프롬프터용)

> 폰이나 태블릿에 띄우고 읽으세요.
> `/` = 짧게 쉬기 (0.3초) · `//` = 확실히 멈추기 (1초) · **굵게** = 힘줘서
> ⏺ = 새 컷 (여기서 카메라 각도나 사이즈를 바꿔 다시 찍기)

---

⏺ 대표님들, / 마케팅 공부할수록 더 어려워지시죠?

⏺ 릴스도 하고, / 네이버도 하고, / 스레드도 하고, / AI도 배우고…

⏺ 대행사까지 써봤는데, / 이상하게 우리 브랜드랑은 안 맞고.

⏺ //
그렇다면 잠깐, / **공부를 멈춰주세요.**

⏺ 18년차 마케터인 제가, / 오늘 딱 3분 동안 / "이 책부터 읽으세요"라고 말씀드릴게요.

---

⏺ 저는 광고학을 전공했고, / 국내외 대기업에서 **18년간** 마케팅을 했습니다.

⏺ 그리고 지금은 / 스몰 브랜드 대표님들의 마케팅과 브랜드를 돕고 있어요.

⏺ 오늘은 그런 제가 / **직접 읽고, 직접 돈 주고 산 책** 중에서, /
대표님께 딱 한 권만 추천한다면 어떤 책인지 이야기해보려고 합니다.

⏺ *(책을 들며)* 바로 이 책입니다. / **『스타트 위드 와이』.**

---

⏺ 대표님들이 마케팅을 어려워하는 이유는, / 사실 방법을 몰라서만은 아니라고 생각해요.

⏺ 뭘 해야 하는지는 / **너무 많이** 압니다.

⏺ 릴스 해야 하고, / 블로그 해야 하고, / 검색 노출도 해야 하고, / 광고도 해야 하고…

⏺ 그런데 문제는, / **"그래서 나는 뭘 해야 하지?"** 가 되는 거예요.

⏺ 누가 릴스가 좋다고 하면 릴스 하고, / 스레드가 좋다고 하면 스레드 하고, /
AI가 대세라고 하면 AI를 배우고…

⏺ 그러다 보면 / 열심히는 하는데, / **브랜드가 점점 더 복잡해집니다.**

---

⏺ 그런데 이 책은 / 여기서 완전히 다른 질문을 던집니다.

⏺ //
**WHAT이 아니라, / WHY를 먼저 생각하라.**

⏺ 이 책에서 말하는 WHY는 / "돈을 많이 벌고 싶다"가 아닙니다. / 돈은 **결과**예요.

⏺ WHY는 / 왜 이 일을 하는지, / 무엇을 믿는지, /
왜 이 브랜드가 존재하는지에 대한 질문입니다.

⏺ *(자막 카드 — 낭독 없음)*

⏺ 대표님, / 이 질문에 지금 바로 답할 수 있으세요?
//  ← 여기 1초 무음. 편집에서 반드시 살리기.

---

⏺ 만약 조금 망설여진다면, / 이 책을 꼭 한번 읽어보셨으면 좋겠습니다.

⏺ 이 책의 가장 유명한 개념이 / 바로 **골든서클**입니다.

⏺ WHAT. / HOW. / 그리고 **WHY.** /
WHAT은 / 우리가 무엇을 파는지. /
HOW는 / 어떻게 다르게 하는지. /
그리고 가장 안쪽에 있는 WHY는, / **왜 하는지**입니다.

⏺ 사이먼 시넥은 / 이 개념을 이렇게 한 문장으로 정리했어요.

⏺ *(인용 자막 카드)*

⏺ 저는 이 문장이 / 이 책의 핵심을 가장 잘 보여준다고 생각해요.

⏺ 우리는 보통 고객에게 / **WHAT부터** 이야기합니다. /
"저희는 이런 제품을 판매합니다." /
"가격은 얼마고, 이런 혜택이 있습니다." /
그런데 이 책은 / **WHY부터** 이야기하라고 합니다.

---

⏺ 책에서는 / 애플을 예로 들어요.

⏺ 만약 애플이 이렇게 말했다면 어떨까요? /
"우리는 훌륭한 컴퓨터를 만듭니다." /
"디자인이 예쁘고 사용하기 편합니다." /
"하나 사시겠어요?"

⏺ *(어깨 으쓱)* … 글쎄요.

⏺ 그런데 애플은 / 제품부터 이야기하지 않죠.

⏺ *(자막 카드 — 낭독 없음)* **Think Different.**

⏺ 우리는 다르게 생각합니다. / 그리고 그 믿음을 / **제품으로 보여주는** 거예요.

⏺ 그래서 사람들은 / 단순히 컴퓨터를 사는 게 아니라, /
그 브랜드가 **믿는 것**을 함께 선택하게 됩니다.

---

⏺ 그래서 저는 이 책을 / 단순한 마케팅 책이라고 생각하지 않아요.

⏺ 릴스 만드는 방법이나 / 광고 세팅 방법은 / 계속 **바뀝니다.** /
하지만 / 내가 왜 이 일을 하는지는 / **쉽게 바뀌지 않거든요.**

⏺ WHY가 선명하면, / 어떤 콘텐츠를 만들지, / 어떤 고객을 만날지, /
어떤 상품을 만들지, / 심지어 **무엇을 하지 않을지**도 / 결정하기 쉬워집니다.

⏺ 마케팅을 계속 공부하는데도 / 점점 더 복잡해지고 있다면… //
새로운 걸 하나 더 배우기 전에, / **내 브랜드의 WHY부터 찾아보세요.**

---

⏺ 제가 오늘 보여드린 건, / 제가 이 책에 그어놓은 밑줄 중 / 정말 일부예요.

⏺ 라이트 형제 이야기부터, / 신뢰가 만들어지는 원리, /
WHY를 조직에 어떻게 적용하는지까지 / 더 많은 이야기가 들어 있습니다.

⏺ 특히 사업을 시작하시는 분, / 이미 하고 계시지만 /
브랜드의 방향이 자꾸 흔들리는 분이라면 / 한번 읽어보셨으면 좋겠어요.

⏺ *(책을 내밀며)* 마케팅 책을 딱 한 권만 추천해달라고 하면, /
저는 이 책을 추천하겠습니다. / **『스타트 위드 와이』.**

⏺ 책 구매 링크는 / 영상 설명란에 남겨둘게요. /
그리고 이 링크는 / 쿠팡 파트너스 활동을 통해 /
제가 일정 수수료를 지급받을 수 있는 링크입니다.

⏺ 마케팅을 더 공부하기 전에, / 오늘은 딱 하나만 생각해보세요. //
**나는 왜 이 일을 하고 있지?**

⏺ 그 질문의 답을 찾는 데 / 이 책이 도움이 될 거예요. /
다음에도 제가 직접 읽어보고 / 정말 추천하고 싶은 책만 가져올게요. /
다음 영상에서 만나요.
