## 촬영 가이드

**세팅**
- 카메라 눈높이, 얼굴이 화면 상단 1/3에 오도록. 배경은 책장 또는 단색 벽.
- 자연광 45도 측면 + 반사판(흰 종이도 가능). 역광·천장 형광등 직하 금지.
- 마이크는 무조건 별도로. 핀마이크나 폰 녹음 앱을 입 가까이 두고 **따로 녹음** 후 편집에서 싱크.
- 컷마다 **각도나 사이즈를 바꿔서** 재촬영 → 점프컷이 자연스러워집니다. (정면 / 살짝 측면 / 클로즈업 3종을 돌려쓰기)

**촬영 순서 (효율 순)**
1. C1–C5 훅 구간을 **3~4번 반복 촬영**. 이 구간만 잘 나오면 영상의 절반은 성공입니다.
2. 나머지 토킹 컷(C6~C40)을 위에서 아래로 순서대로.
3. 책 B-roll 한 번에 몰아서: 표지 정면 / 표지 회전 / 페이지 넘기기 / 밑줄 클로즈업 3컷 / 책 내려놓기.
4. 화면 B-roll(릴스·네이버·스레드·AI 강의)은 화면 녹화로 각 3초씩.

**낭독 톤**
- 훅(0:00–0:32): 빠르고 단정하게. 밀어붙이기.
- 본론(1:00–4:28): 반 박자 느리게. 문장 사이 0.3초씩 쉬기.
- 마무리(5:04~): 가장 느리게, 목소리 낮춰서.

## 편집 가이드

| 항목 | 설정 |
|---|---|
| 컷 간격 | 평균 6~8초. 30초 이상 같은 앵글 금지 |
| 자막 위치 | 화면 하단에서 위로 15% 지점 (YouTube UI 회피) |
| 자막 폰트 | Pretendard Bold 또는 나눔스퀘어 ExtraBold. 한 줄 15자 이내 |
| 자막 강조 | 키워드 1~2개만 컬러(브랜드 컬러) 또는 형광 밑줄 |
| 풀스크린 카드 (T1~T5) | 배경 단색, 최소 2.5초 유지, 페이드 0.3초 |
| BGM | 잔잔한 로파이/피아노, 목소리 대비 12~15% |
| BGM 컷 | 0:20(정지), 1:52(카드), 2:20(질문 후 무음 1초), 5:04(마지막 질문) — 총 4회 |
| 무음 구간 | 0:20, 2:20, 5:04 — 이 3곳은 반드시 살리기 |
| 자막 싱크 | 녹음 후 CapCut 자동자막 → `03-subtitles.srt`의 문장으로 오탈자 교정 |
