
## 자막

`start-with-why.srt` 를 유튜브 자막으로 그대로 업로드하면 됩니다.
보이스오버 녹음 후 실제 발화와 어긋나면 유튜브 자막 편집기에서 타임코드만 미세 조정하세요.

## 촬영 체크리스트

**A. 정면 토크** — 후킹 / 스텔라 소개 / 마케팅이 어려운 이유 / WHY 설명 /
대표님 질문 / 스텔라의 관점 / 마지막 메시지

**B. 책 B-roll** — 책 들기 · 표지 클로즈업 · 펼치기 · 밑줄 보여주기 ·
읽는 모습 · 카메라 앞으로 · 책상 위에 내려놓기

**C. 마케팅 B-roll** — 노트북 · 릴스 보는 스마트폰 · 네이버 검색 · 스레드 ·
AI 화면 · 노트 필기 · 콘텐츠 캘린더

**D. 그래픽** — 화이트보드 트랙(`start-with-why-whiteboard.mp4`)이 담당.
그 위에 `WHAT / HOW / WHY`, `나는 왜 이 일을 시작했는가?`,
`더 배우기 전에 WHY부터.` 타이포만 얹으면 됩니다.
