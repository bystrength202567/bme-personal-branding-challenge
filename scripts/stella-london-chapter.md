# 스텔라 — 런던 챕터 (서사 전략 Addendum)

> binlee_english 글의 전략 원리 중 **콘텐츠 품질·포지셔닝에 관한 부분만** 가져오고, 사실이 아닌 감정을 먼저 깔아 안티를 방어하는 방식은 쓰지 않는다.

## Core Principle
포맷은 전략적으로 설계하되, **이유는 꾸미지 않는다.** 진짜 이유 하나를 정직하게 말하는 것 자체가, 가짜 서사보다 강한 콘텐츠다.

> ⚠️ **적용하지 않은 부분** — 원문의 "동정표로 안티 방어"는 사실이 아닌 두려움·번아웃 서사를 먼저 깔아 향후 행보를 면피하는 기법이다. 스텔라 채널의 핵심 메시지("진짜 강점을 진정성 있게 전달하라")와 정면으로 충돌하므로 이 전략에서는 배제한다. 실제로 느끼는 감정이 있다면 그것만 담는다.

## 1. 원문에서 가져온 것 vs 버린 것

| 원문 | 가져온 것 |
|---|---|
| 미장센 업그레이드 — 예쁜 배경으로 퀄리티만 올리기 | 배경을 콘텐츠 소재로 통합 — 런던 거리의 간판·건축을 "브랜딩 현장 답사"로 촬영 (2화 건물 비유와 연결) |
| 프리미엄 광고주 유치 — 해외살이 이미지 소비 | 해외 진출 세그먼트 신규 타깃팅 — 기존 타깃(1인대표·전문직·창업자) 중 해외 진출 고민층을 위한 콘텐츠 라인 신설 |
| 본업 복귀 명분 — 동기를 감추고 "도전기"로 양쪽 다 유리하게 포장 | 저널 다큐 톤 유지, 단 동기는 1문장으로 투명하게 공개 |
| 동정표(안티 방어) — 사실 아닌 두려움·번아웃 서사 선공개 | **적용하지 않음** — 실제 감정만, 꾸며내지 않는다 |

## 2. 공개 영상 대본 템플릿 (채워 넣을 자리)

채워야 할 것: **① 런던으로 가는 진짜 이유 (1문장)** · **② 지금 실제로 느끼는 감정 (있는 그대로)** · **③ 콘텐츠에서 바뀌는 것 / 안 바뀌는 것**

**[스텔라]**

> "저, 런던으로 갑니다."
>
> *(담담하게. 예고 없이 바로 — 1화 오프닝과 같은 톤)*
>
> **[진짜 이유 — 1문장. 예: "해외 진출을 고민하는 대표님들이 늘면서, 현지 사례를 직접 보고 배우고 싶었습니다" / 개인적인 이유라면 있는 그대로]**
>
> **[지금 실제로 느끼는 것 — 기대/불안/둘 다, 사실대로]**
>
> "앞으로 런던 거리의 간판과 가게들을, 브랜딩 사례로 보여드릴 거예요. 해외에서 자기만의 자리를 만든 1인 대표들도 직접 만나보려 합니다."
>
> "장소는 바뀌어도, 원칙은 그대로입니다. 가격이 아니라 이유로 선택받는 법. 그 얘기는 계속합니다."

## 3. 새 콘텐츠 라인
기존 "매회 다른 장르를 빌려오는" 포맷 규칙은 유지하고, 장르 후보에 추가:
- **여행 저널 — 런던의 간판들** (오프라인 브랜딩 사례)
- **현지 인터뷰 — 해외에서 자리 잡은 1인 대표**

## 4. 그대로 유지할 것
- 메인 캐치프레이즈 "가격 말고, 이유" — 장소가 바뀌어도 아웃트로에 그대로 반복
- 타깃은 그대로 1인 대표·전문직·창업자 — 해외 진출 세그먼트는 **확장**이지 교체가 아니다
- 날것의 즉흥성 — 런던 생활도 편집으로 과장하지 않고, 실제 반응을 그대로
- 동기는 항상 투명하게 — 콘텐츠 방향이 바뀔 때마다, 왜 바뀌는지 먼저 말한다
