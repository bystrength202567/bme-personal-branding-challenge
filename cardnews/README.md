# 카드뉴스 메이커

B, Me 브랜드 톤으로 인스타그램 카드뉴스(1080 × 1080)를 만들고 PNG로 저장하는 도구입니다.
빌드 과정이 없고 외부 라이브러리도 쓰지 않습니다. `cardnews/index.html`을 브라우저로 열면 바로 동작합니다.

배포된 사이트에서는 `/cardnews` 주소로 열립니다.

## 쓰는 법

1. 왼쪽에서 카드를 고르고, 오른쪽에서 문구를 고칩니다. 고치는 즉시 가운데 미리보기에 반영됩니다.
2. `이 카드 PNG` 로 현재 카드를, `전체 PNG` 로 모든 카드를 순서대로 내려받습니다.
   파일 이름은 `bme-cardnews-01.png` 처럼 순번이 붙습니다.
3. 편집한 내용은 브라우저 `localStorage` 에 자동 저장됩니다. 다른 기기로 옮기거나 백업하려면
   `JSON 저장` 으로 파일을 내려받고, 나중에 `JSON 불러오기` 로 되돌리면 됩니다.

## 문구 작성 규칙

| 표기 | 결과 |
| --- | --- |
| `*강조*` | 그 구간만 브랜드 컬러 이탤릭 (본문의 `em` 과 같은 스타일) |
| 줄바꿈 | 입력한 그대로 카드에 반영 |
| `라벨 \| 내용` | 목록 카드에서 작은 라벨 + 본문 한 줄. 라벨이 없으면 `\| 내용` 처럼 앞을 비워 둡니다 |

글자 수가 많으면 정해진 영역에 맞게 크기가 자동으로 줄어듭니다. 그래도 넘칠 만큼 길면 문장을 나누세요.

## 템플릿

| 이름 | 쓰임 |
| --- | --- |
| 표지 | 첫 장. 로즈 패널 + 태양 그래픽에 큰 제목 |
| 한 문장 | 질문이나 선언 한 줄을 가운데 크게 |
| 번호 + 설명 | `01`, `02` 처럼 번호를 붙인 설명 카드 |
| 목록 | 6주 커리큘럼, 대상 안내처럼 항목이 여러 개일 때 |
| 신청 안내 | 마지막 장. 모집 일정과 신청 문구 |

배경은 페이퍼 · 로즈 · 옐로 · 라벤더 · 민트 · 잉크 여섯 가지이며, 각 배경마다 본문 · 강조 · 구분선 색이 함께 바뀝니다.

## 구조

- `index.html` — 편집 화면
- `cardnews.css` — 편집 화면 스타일 (카드 디자인과는 무관)
- `cardnews.js` — 카드 데이터, 캔버스 렌더러, PNG/JSON 내보내기

카드는 DOM이 아니라 캔버스에 직접 그립니다. 미리보기와 저장이 같은 렌더링 코드를 쓰기 때문에
화면에 보이는 그대로 저장됩니다. 새 템플릿은 `cardnews.js` 의 `TEMPLATES` 에 `fields` 와 `draw` 를
추가하면 편집 화면에도 자동으로 나타납니다.

제목용 DM Serif Display 는 Google Fonts에서 불러옵니다. 오프라인에서 열면 기본 세리프로 대체되어
글자 모양이 달라지므로, 최종 이미지를 뽑을 때는 인터넷에 연결된 상태로 저장하세요.
