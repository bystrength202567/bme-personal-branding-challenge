# B, Me 퍼스널 브랜딩 챌린지

정적인 MVP입니다. 로그인·개인별 데이터·공개 브랜드 북·커뮤니티를 Supabase로 연결하기 위한 화면 흐름을 포함하며, 현재 데모 데이터와 개인 기록은 브라우저 `localStorage`에 저장됩니다.

## 배포

Vercel에서 이 저장소를 import하면 별도의 빌드 과정 없이 배포됩니다.

## Supabase 연결 시 필요한 테이블

- `profiles` — 사용자 프로필과 졸업 여부
- `daily_answers` — 일자별 1문 1답
- `mission_progress` — 미션 완료와 업로드 자료 URL
- `brand_books` — 공개 여부가 있는 브랜드 북
- `community_posts` — After B, Me 게시물

인증은 Supabase Auth의 이메일 매직 링크 또는 Google 로그인으로 구성하는 것을 권장합니다. 공개 브랜드 북과 게시물에는 RLS 정책으로 `is_public = true`인 항목만 비로그인 사용자에게 노출해야 합니다.

## 달빛 한국사 여행 (`/history`)

고조선 · 삼국시대 · 통일신라 · 고려 · 조선 · 대한제국 중 시대를 골라 들어가는 한국사 학습 앱입니다. 한국어/영어(KO/EN)를 지원합니다.

- 시대별 소개 · 연표 · 인물 · 재미있는 사실 · 퀴즈 (3/4 이상 정답 시 도장, `localStorage` 저장)
- **캐릭터로 입장하기**: 닉네임과 캐릭터를 고르고 시대별 3D 공간(아사달·서라벌·한양 등)에 입장
  - 바닥 클릭/탭 이동, 드래그 회전, 휠·핀치 확대, WASD/방향키 이동
  - 위인 NPC와 대화, 이야기 비석 읽기, 시험관 퀴즈로 도장 획득
  - 인사하기 · 악수하기 · 만세하기 · 말 걸기 (가까운 위인이 인사·악수로 답해요)
  - 주민은 컴퓨터가 움직이는 캐릭터이며, 실제 다른 접속자와 함께하는 멀티플레이는 아직 없습니다
- 이름 + 생년월일로 보는 6개 시대 전생 결과, 이미지 저장
- **조선 · 경복궁** (`palace.js`)
  - 광화문(홍예문 3개)·해치 → 흥례문·금천·영제교 → 근정문 → 근정전(2단 월대, 품계석, 박석, 어좌와 일월오봉도) → 사정전 → 강녕전·교태전(용마루 없음) → 아미산 굴뚝, 서쪽 경회루(48개 돌기둥), 북쪽 향원정·취향교, 수정전·자선당, 뒤편 북악산
  - 캐릭터 꾸미기: 왕·왕비·세자·공주·문관·무관·상궁·내관, 옷 색·장식/치마 색·피부색·노리개, 이름 정하기, 3D 미리보기
  - 접속한 사람의 현재 시각에 따라 새벽·아침·낮·오후·저녁·밤으로 하늘·햇빛·그림자·창호 불빛이 바뀜 (시간 버튼으로 다른 시간대 미리보기)
  - 건물 안내판 16곳, 지도로 순간이동, 과거 시험관 퀴즈
  - 실제 궁궐을 단순화한 모형이며, 주요 전각의 배치 순서와 특징을 살렸습니다

파일 구성: `data.js`(한국어 콘텐츠·3D 공간 설정), `data.en.js`(영어 콘텐츠), `app.js`(화면·언어), `world.js`(3D 엔진·시대별 공간), `palace.js`(경복궁). 3D 공간은 입장할 때 cdnjs에서 three.js r128을 불러옵니다.
